# Review templates

These files expose the frozen v2 schemas without study rows. The complete reviewer guide is [Human review](../docs/HUMAN_REVIEW.md), and the synthetic worked examples are in [human review calibration](../docs/HUMAN_REVIEW_CALIBRATION.md).

`claim1_first_stage.csv` records four source-cell clarity judgments and two ordinary-sense judgments. `claim1_second_stage.csv` records holder and normative-object stability only after the first-stage consensus gate. `claim2_rewrite.csv` records one preservation judgment with conditional diagnostics. `reviewer_metadata.json` records eligibility, independence, and work sessions.

Do not add study rows to this public directory. Licensed source text and blinded row-filled packages remain outside the repository.
