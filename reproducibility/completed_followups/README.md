## Carrier-reader and mediation

The carrier-reader study tests one selected discovery history pair and two
behavior-known reserved pairs. It swaps saved value activations before the
question while holding model weights and questions fixed. The selected broad
carrier transfers all four tested joint answers and preserves all eight direct
checks. No compact carrier set was recovered: none of the 64 single-site tests
gave the complete effect. Reserved pairs transfer only two of four and one of
four answers. They fail the full criterion and are not a prevalence sample.
Across measured nonbaseline rows, all 1,416 direct checks remain correct, while
179 recipient joint answers change from correct to wrong. Some are deliberate
transfers from a wrong-answer donor.

The mediation follow-up reuses one discovery pair. It intervenes on candidate
writer contributions, the fixed carrier and candidate reader outputs, with the
same model and questions. The selected writer transfers none of the four hard
answers. The selected eight-head fallback reader set misses its qualification
threshold. Blocking that set removes all hard transfers; injection restores
four of four, while continuous effects remain incomplete. All 948 measured
direct rows stay correct. These repeated measurements establish partial
functional mediation, not a unique, minimal or naturally necessary mechanism.
