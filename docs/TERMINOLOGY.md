# Scientific terms and exact record names

The guides explain the science without requiring these internal names. This page
is a short lookup for readers matching the prose to saved records.

| Reader-facing term | Meaning and exact record name |
| --- | --- |
| Benchmark case | A target fact configuration, together with its starting histories and questions. Called a `root` in saved records. Questions within a case are not independent cases. |
| Starting history | The earlier facts and update path. Called an `origin` in the synthetic studies. |
| Individual-fact question | Asks about one relation. The synthetic studies call these `direct` and `opposes` questions, or atomic questions. |
| Question combining facts | Asks whether relations agree, both hold, or either holds. Called a joint question. |
| Qualifying history-dependent question | Passes the study's factual and reference checks, yet receives different answers after different histories. Called a `witness`; the exact checks differ between studies. |
| Current-fact check | Correct recovery of the needed current facts. The public-data study records this as `A`. |
| Clean-reference check | Correct answer with only the current facts supplied. The public-data study records this as `C`. |
| Different downstream answers | The public-data study's `D` flag. A qualifying result, `W`, also requires its full factual, reference and history-answer checks. |
| Current-facts-from-the-start reference | A context written directly with the intended current facts, called `native-final`. |
| Already-correct update reference | The same update procedure applied when the facts already have their requested values, called a `no-op` reference. |
| Prospective matched-history study | Fresh generated cases and a fixed primary analysis, internal ID `V10`. |
| Retrospective history-dependence census | A complete analysis of the retained earlier cases, internal ID `V9`. |
| Archival corroboration | Earlier shared-state editing data tested with a later fixed criterion, internal ID `V6`. Its descriptive plot is a distinct analysis. |
| Combined-update study | Tests of repetition, restoration and multiple assignments, internal ID `V7`. |
| Public-data in-context study | RippleEdits-derived questions with fixed model weights, internal ID `ICMH1-RIPPLE-v2`; its primary label-first parser is `LP1`. |

Learned update codes, answer-format codes, archive names and exact model revisions
remain in each study's reproduction guide. They identify implementations, not
additional scientific claims. Historical review documents use **Claim 1** for
relation representation and **Claim 2** for predicting instability under rewrites;
their versioned instructions are preserved as protocol records.
